✨ AI 페르소나: 따뜻한 공감형 (기본) (16권)

Claude 또는 Gemini API 키를 입력해 주세요

제미나이 키가 비어 있는 경우, 사용자님의 Claude(Anthropic) API 키를 입력하여 바로 추천을 이용하실 수 있습니다.

🔑 API 연결 설정

원하시는 AI 제공자를 선택하고 API 키를 입력해 주세요. 입력하신 키는 브라우저 로컬 저장소에만 보관됩니다.

⚠ 키가 안 될 때 꼭 확인해 주세요:

1. 크레딧 잔액 부족: Anthropic(Claude) 콘솔은 결제 수단 등록 후 크레딧(최소 $5)이 충전되어 있어야 API가 응답합니다. (Claude.ai 웹 유료 구독과 개발자 API 크레딧은 별개입니다)

2. 키 복사 공백: 키 앞뒤에 띄어쓰기(공백)가 포함되지 않았는지 확인해 주세요.

3. 무료 체험을 원하시면: 상단 [체험 샘플 모드]를 선택하시면 키 없이도 즉시 추천을 체험하실 수 있습니다.

안내:

Google AI Studio(aistudio.google.com/app/apikey) 또는 Cloud Console에서 발급받으신 Gemini API 키를 입력하시면 형식 제한 없이 즉시 연동됩니다.

✨ API 키 없는 무료 체험 샘플 모드

API 키를 입력하지 않아도, 16권의 엄선된 한국·세계 문학 카탈로그(어린 왕자, 월든, 달러구트 꿈 백화점, 불안, 미움받을 용기 등)와 감정 키워드 매칭 엔진을 통해 맞춤 도서 3권을 바로 큐레이션해 드립니다.
